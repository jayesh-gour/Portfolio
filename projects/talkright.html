TalkRight

An English-practice chatbot that corrects grammar and phrasing like a close friend would — never like a strict teacher.

Live Demo View on GitHub

⚠ The free-tier demo may take ~30–60 seconds to wake up.

Streamlit UI→ FastAPI /chat→ Prompt layer→ Gemini API→ Correction + reply

Problem

Practicing English conversation feels risky when every mistake gets flagged in a clinical, judgmental tone — that discourages exactly the people who need the practice most.

Solution

TalkRight takes casual, typo-included input, corrects grammar and phrasing, then replies conversationally — tuned through explicit tone rules and few-shot examples in the system prompt so responses never sound robotic or third-person.

Key features

✓Natural-language grammar & phrasing correction
✓Warm, casual conversational replies
✓Few-shot prompt engineering for consistent tone
✓FastAPI backend, Streamlit frontend
✓Custom dark indigo/violet UI with correction badges
✓Deployed on Render + Streamlit Community Cloud

Engineering challenges

Challenge

Google deprecated multiple Gemini model versions mid-project (gemini-2.0-flash → gemini-2.5-flash-lite), breaking the app in production each time.

Solution

Migrated to the gemini-flash-latest alias instead of pinning a specific model version, so future deprecations no longer require a code change.

Challenge

Render deployment failed with a grpcio-status dependency conflict — requirements.txt accidentally mixed frontend (Streamlit, pandas) and backend dependencies with pinned versions.

Solution

Split into clean, unpinned, backend-only and frontend-only requirement files, and kept API error responses in the same shape ({"message": ...}) as success responses so the frontend never breaks on failure.

What I learned

Real production incidents — a third-party model getting deprecated, a dependency conflict on deploy — taught me more about resilient API design than the initial build did. Aliasing instead of pinning, and keeping response shapes consistent even in failure, are lessons I now apply by default.
