Gwen

A personal AI assistant that runs on local models and routes each request to the right one.

[PLACEHOLDER: 2–3 sentences about why local-first — e.g. privacy, offline capability, cost of cloud LLMs — in your own words.]

Solution

Built with Google ADK and Ollama. Breaks user requests into structured tasks and runs them in sequence with dependency handling; routes general vs. technical queries to specialized local models (Granite 4.2 3B for general use, Qwen3 4B for technical tasks); long-term memory stored in PostgreSQL via SQLAlchemy; RAG over personal documents with ChromaDB and nomic-embed-text; tools for calculation, weather, and web search; FastAPI backend and Streamlit chat UI.

Key features

✓Runs entirely on local Ollama models — no cloud API calls for inference
✓Orchestrator breaks requests into structured tasks with dependency handling
✓Model router — general vs. technical queries sent to the right model
✓RAG over personal documents with ChromaDB and nomic-embed-text
✓Long-term memory in PostgreSQL via SQLAlchemy
✓Tools: calculation, weather, and web search
✓FastAPI backend with clean REST interface
✓Streamlit chat UI
