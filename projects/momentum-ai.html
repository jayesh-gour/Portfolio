Momentum AI

An AI accountability coach that journals your day, then tells you — honestly and kindly — whether you're closing the gap to your goal.

⚠ Demo notice

Demo only — please don't enter real personal information.

Live Demo View on GitHub
Streamlit UI→ FastAPI backend→ SQLAlchemy / SQLite→ Gemini API→ AI feedback

Problem

Journaling apps record what happened, but rarely tell you whether you're actually moving toward what you set out to do. Most give the same generic encouragement regardless of the day's content.

Solution

Users set a goal during onboarding (screen time, study hours, workout hours, plus free-text targets). Each day, they write a diary entry. On save, the backend builds natural-language goal context, pulls yesterday's stored analysis, and sends both to Gemini alongside today's entry. Gemini returns estimated productive/wasted hours and a warm, non-judgmental suggestion — encouraging if today was better than yesterday, gentle if it wasn't.

Key features

✓Goal-setting onboarding flow
✓Daily journaling with full CRUD
✓Day-over-day AI progress comparison
✓Relational schema — User, UserProfile, DiaryEntry
✓SQLAlchemy relationships with cascade deletes
✓Multi-page Streamlit interface via session-state routing
✓Search across past entries
✓Sign up / login (plain-text auth — flagged limitation)

Engineering notes

Known limitation

Authentication currently stores passwords in plain text. This is a deliberate, clearly-flagged limitation for this stage of the project — proper hashing (e.g. bcrypt) and JWT-based sessions are a planned next step, not an oversight.

Design decision

The relational schema uses real foreign keys and cascade="all, delete-orphan" so deleting a user cleanly removes their profile and diary entries — avoiding orphaned rows without manual cleanup logic.
